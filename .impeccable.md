## Design Context

### Users

Small private household. The app is a personal tool, not a public product. The audience tolerates — and appreciates — irreverence. No need to sand every edge for a general public.

### Brand Personality

Practical, irreverent, unapologetically purple. The sardonic robot loading messages ("Processing. Your impatience is noted and ignored.") set the voice register: competent, a little dry, doesn't perform warmth it doesn't mean.

### Aesthetic Direction

- **Primary theme: dark.** `#0f0f23` backgrounds, `#1a1a2e` surfaces, royal purple (`#7c3aed`) as the brand accent. Light mode exists but dark is the real experience.
- Mobile-first, full-screen Ionic/Capacitor app.
- Type system "Highway" (see `apps/mobile/src/theme/typography.scss`): Barlow for body, page titles and section labels; Overpass (a Highway Gothic revival) for aisle names in the shopping list header bars; Barlow Condensed for tab and form-field labels; JetBrains Mono for data text such as counts and codes (monospace-as-data-register, not monospace-as-personality; item quantities are Barlow semibold with tabular digits, since mono read poorly at that size); Noto Emoji for single-color aisle-plate emoji. All bundled via @fontsource.
- No glassmorphism, no glow borders. The purple should do the heavy lifting.
- Anti-reference: anything that looks like a generic health/wellness or grocery startup app.

### Design Principles

1. **Utility first, character second** — every visual element earns its place by making the app easier to use. Personality comes from small moments (copy, micro-details), not decoration.
2. **Dark surfaces, clear hierarchy** — use the stepped background colors and purple accent to create depth without reaching for shadows or gradients.
3. **Monospace for data, Barlow for prose** — counts and codes go in JetBrains Mono; item quantities stay Barlow (semibold, tabular digits) so they read cleanly beside the name. Labels, names and page titles are Barlow; aisle names are Overpass (`var(--app-font-sign)`); tab and form-field labels are Barlow Condensed (`var(--app-font-display)`).
4. **Compact but breathable** — this is a mobile app used while cooking or shopping. Rows should be tappable (min 44px) but not wasteful. Tight grouping, generous section breaks.
5. **Irreverence in copy, restraint in visuals** — the voice can be dry and direct; the visuals should be clean and focused.
